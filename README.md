# FFXIV Graphics Reference CN

> 中文 FFXIV 图形渲染与 Mod 制作参考手册

## 项目简介

FFXIV Graphics Reference CN 是一个面向中文社区的开放技术文档项目。

本项目旨在系统整理 Final Fantasy XIV 的图形渲染相关知识，包括但不限于：

- Shader Reference
- Material（MTRL）
- Texture
- Colorset
- Shader Key
- Material Constant
- Vertex Color
- Penumbra
- TexTools
- Blender Workflow

本页面目标是建立一套适合中文mod社区长期维护的原创技术文档。
