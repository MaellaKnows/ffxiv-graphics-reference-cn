# Mod制作

> 本章节会简单介绍 FFXIV Mod 制作流程，并且提供一些mod制作教程。

---

## 主要流程


资源提取
↓
制作
↓
导入
↓
mod打包
↓
游戏内测试


---

## Supported Workflow

| Stage | Tool |
|---|---|
| Asset Extraction | TexTools |
| Mod Loading | Penumbra |
| Model Editing | Blender |
| Texture Editing | Photoshop / GIMP |
| Material Editing | Textools / Raw Editing |
