# FFXIV Graphics Reference CN

欢迎来到 **FFXIV Graphics Reference CN (GRC)**。

这是一个专注于 **Final Fantasy XIV 图形渲染、Shader 与 Mod 制作** 的中文参考文档。

本站内容主要包含：

- FFXIV Shader 解析
- Material（`.mtrl`）结构说明
- Texture（`.tex` / `.dds`）解析
- Mod 制作工作流
- 常用工具与开发资料

所有 Shader 内容均基于社区资料整理、验证与翻译，并结合实际 Mod 制作经验进行补充。

资料来源：<https://xivmodding.com/>

## 常用文件格式

| 格式 | 说明 |
|------|------|
| `.mdl` | 模型文件 |
| `.mtrl` | 材质文件 |
| `.tex` | FFXIV 纹理 |
| `.dds` | 通用纹理 |
| `.pap` | 动画 |
| `.avfx` | 特效 |
